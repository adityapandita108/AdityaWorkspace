- Floating geometric shapes (circles, squares, triangles) for visual depth

- Personal info cards: Location, Education, Experience, Interests
- Alternating left/right timeline layout with CSS animations

</details>

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/adityapandita/portfolio-v1.git

# Navigate to the folder
cd portfolio-v1

# Open in browser (no build needed!)
open index.html

# For contact form — host on a PHP-enabled server
# Update backend.php with your email:
# $adminEmail = "your-actual@email.com";
```

> ⚡ **Zero dependencies.** No npm. No build tools. Pure HTML, CSS & JS.
